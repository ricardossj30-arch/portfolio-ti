# Projeto 1 — Diagnóstico de Computador com Windows 11

## Objetivo

Realizar um diagnóstico básico de um computador com Windows 11, identificando informações do sistema, características de hardware, utilização de recursos e condições gerais de funcionamento.

## Ferramentas utilizadas

- Informações do Sistema (`msinfo32`)
- Gerenciador de Tarefas
- Segurança do Windows
- Prompt de Comando

## Ambiente analisado

- **Sistema operacional:** Windows 11 Home
- **Fabricante:** Lenovo
- **Processador:** AMD Ryzen 7 7735HS with Radeon Graphics
- **Memória RAM:** 8 GB DDR5, 4800 MT/s
- **Armazenamento:** SSD de aproximadamente 237 GB

## Procedimentos realizados

1. Consulta das informações do sistema operacional e do hardware.
2. Verificação da memória RAM e dos recursos utilizados.
3. Consulta da capacidade e do espaço disponível no armazenamento.
4. Observação dos processos ativos no Gerenciador de Tarefas.
5. Verificação da área de desempenho e integridade do dispositivo na Segurança do Windows.

## Resultados observados

- O sistema apresentou uso inicial de memória RAM de aproximadamente 89%.
- Após fechar aplicativos abertos, o uso de memória caiu para aproximadamente 55%.
- O armazenamento apresentava cerca de 58,8 GB livres.
- A Segurança do Windows não exibiu alertas visíveis na área consultada.
- Não foi observada lentidão durante a verificação após o fechamento dos aplicativos.

## Conclusão

A análise indicou que os aplicativos abertos contribuíam para o uso elevado de memória naquele momento. O uso de RAM diminuiu após o encerramento desses programas.

Os resultados representam as condições observadas durante o teste e não comprovam, isoladamente, a existência ou a ausência de problemas de hardware.

## Aprendizados

- Identificação das principais características de um computador.
- Consulta de informações do Windows.
- Monitoramento básico dos recursos do sistema.
- Registro de evidências e elaboração de conclusões técnicas.
